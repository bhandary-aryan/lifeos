Expected format

The same columns as Export CSV, so an export can be imported again. Download a template.

  • Required: date, type (income, expense, transfer, debt_payment), amount, account.
  • Transfers also need to_account. Debt payments need debt, principal and interest (which must add up to the amount).
  • Accounts, categories and debts are matched by name against yours. Unknown names are reported, never created.
  • Dates like 2026-03-31 or in your preferred format. Amounts like 1234.56 or 1,234.56, never negative — the type sets the direction.
  • Rows that look like transactions you already have are flagged and left unticked.
